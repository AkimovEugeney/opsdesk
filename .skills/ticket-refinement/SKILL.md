# Ticket refinement

Use for a new product ticket before estimating or technical design.

1. Ask the learner to state the business goal and known requirements in their own words.
2. Ask what is ambiguous, which edge cases matter, which dependencies exist, and which risks or unknowns could affect delivery.
3. Answer only the questions the learner asks as Product Owner. Record each answer in the requirements log.
4. Keep hidden learning goals, technical mechanisms, race conditions and the intended implementation undisclosed.
5. Ask for the learner's estimate only after refinement. Then transition to technical design and confirm the work split.

Before presenting the ticket, prepare consistent Product Owner answers from product rules and persist them according to `docs/learning/task-manager.md`. Never retrofit requirements to the learner's proposed solution.
