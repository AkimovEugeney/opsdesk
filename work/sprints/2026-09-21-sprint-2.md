## Sprint Goal

Оператор входит в систему, и обработанный запрос выполняется от имени доверенного пользователя: API подтверждает учётные данные при входе и различает вошедшего пользователя и анонимный запрос.

## Learning goal

Build and explain one trusted identity boundary: the `authentication` concept (`access`, `api`, target UNDERSTAND) — how a request becomes attributable to a real user, what must not be trusted from the client, and how the allowed and denied paths are verified. Permission rules are deliberately out of scope: `authorization` stays for the slice that unblocks OPS-003.

## Known risks / unknowns

The following bullets preserve the planning-time risks, not current readiness. The accepted identity contract and migration are recorded in OPS-006; current evidence gaps are in its acceptance reconciliation. Do not ask the learner to repeat the design or passed understanding check.

- The identity source, the credential-storage decision and the session contract are not decided. These are learner-owned (Red) design decisions: the mentor explains mechanisms and consequences, does not invent the mechanism.
- The database has no credential field: `User` currently stores `id`, `name`, `role`, `createdAt` only, and one migration (`20260815135516_init`) exists. Any credential change needs a migration, which is a data-model decision with its own review.
- The learner has no recorded prior authentication implementation and reported unfamiliar terms on 2026-09-08, so the mechanisms must be taught with worked examples before design is requested.
- The API has no test suite configured; verification is manual HTTP checks plus the local build unless testing is explicitly added.
- The `apps/web` application is still empty (only `AGENTS.md`), so the frontend alternative needs project scaffolding before any learning work starts.
- Development environment: checked 2026-09-22 — the Docker daemon was not running, no `.env` existed under `infra/` or `apps/api/`, no `node_modules` was present and the `pnpm` CLI failed in the agent shell while `npm` worked. Preparing the environment is the first step of the iteration, before any migration can run.
- Engineering-depth question for OPS-006 (one, proportionate): what happens when a client presents a stolen or forged credential, and which invariant keeps a request non-anonymous without providing the credential itself? The verification is the denied path plus a review of the trust boundary.
