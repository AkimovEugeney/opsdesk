Оператор может открыть карточку обращения и увидеть контекст, нужный для дальнейшей работы с ним.

## Context

Список активных клиентских обращений уже доступен оператору. Для работы с конкретным обращением требуется его подробная карточка.

## Visible requirements

- В карточке обращения видны его статус, заголовок, описание и автор обращения.
- В карточке отображается дата создания и, если обращение закрыто, дата закрытия.

## Acceptance criteria

- Оператор может открыть подробную карточку существующего клиентского обращения.
- Карточка содержит статус, заголовок, описание, автора и дату создания обращения.
- Для закрытого обращения карточка содержит дату закрытия.
